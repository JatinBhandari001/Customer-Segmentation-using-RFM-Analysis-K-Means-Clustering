<h1>Customer Segmentation using RFM Analysis & K-Means Clustering</h1>
    <h2>📌 Project Overview</h2>
    <p>
        This project focuses on customer segmentation using the Online Retail dataset.
        The objective is to identify valuable customer groups by analyzing purchasing
        behavior through <strong>RFM (Recency, Frequency, Monetary) Analysis</strong>
        and Machine Learning techniques.
    </p>
    <p>
        By combining RFM scoring, K-Means clustering, and classification models,
        the project helps businesses understand customer behavior, improve retention
        strategies, and design targeted marketing campaigns.
    </p>
    <h2>🚀 Key Features</h2>
    <ul>
        <li>Processed and analyzed 5,000+ retail transaction records</li>
        <li>Performed data cleaning and preprocessing using Python</li>
        <li>Conducted RFM Analysis to measure customer value</li>
        <li>Applied K-Means Clustering to create 3 customer segments</li>
        <li>Built a classification model for customer segment prediction</li>
        <li>Created visualizations to analyze spending patterns and sales trends</li>
        <li>Generated actionable business insights for customer retention</li>
    </ul>

  <h2>🛠 Technologies Used</h2>

        <li>Matplotlib</li>
        <li>Seaborn</li>
        <li>Scikit-learn</li>

    </ul>
    <h2>📊 Project Workflow</h2>
    <ol>
        <li>Data Collection and Understanding</li>
        <li>Data Cleaning and Preprocessing</li>
        <li>Feature Engineering (RFM Metrics)</li>
        <li>RFM Scoring and Customer Segmentation</li>
        <li>K-Means Clustering</li>
        <li>Data Visualization</li>
        <li>Classification Model Development</li>
        <li>Business Insights and Recommendations</li>
    </ol>
    <h2>📈 Results</h2>
    <ul>
        <li>Identified High-Value, Regular, and Low-Value customer segments</li>
        <li>Discovered that a small percentage of customers contribute a significant share of revenue</li>
        <li>Successfully grouped customers based on purchasing behavior</li>
        <li>Demonstrated how machine learning can support customer retention and targeted marketing strategies</li>
    </ul>  
    <h2>💼 Business Impact</h2>
    <p>The project enables businesses to:</p>
    <ul>
        <li>Identify loyal and high-value customers</li>
        <li>Design personalized marketing campaigns</li>
        <li>Improve customer retention strategies</li>
        <li>Optimize resource allocation based on customer value</li>
